# 张蕤和 Ruihe Zhang — 个人主页

面向中国 HR 和业务面试官的个人作品集，核心定位为：

> 数据分析 · 商业分析 · 金融风控  
> 把复杂数据，变成可验证的业务判断。

## 信息结构

- 首屏展示 2027 届、目标岗位、麦吉尔和 Scotiabank 等核心信号
- 55%、130,176、1,100+ 和全球第 2 等可核验成果
- 信用风险、商业智能和机器学习工程三类能力
- Scotiabank、McGill EPS、BIXI 和 Scope-AI-Thon 代表项目
- 实习研究时间线、教育、技能、证书和双语简历下载

## 设计规则

详细规则见 [`DESIGN.md`](./DESIGN.md)。视觉融合 IBM 的企业级网格、Mastercard 的暖色留白、Apple 的克制与 WIRED 的编辑型信息层级。

## 本地预览

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

静态站点会输出至 `dist/client`。

## GitHub Pages 发布

将项目推送至 `ruihezhang.github.io` 仓库的 `main` 分支，并在 Pages 设置中选择 **GitHub Actions**。仓库内的工作流会自动构建和发布。
